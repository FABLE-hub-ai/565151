# Ала-Тоо Inn

Локальный сайт отеля с отдельными страницами, бронированием в SQLite и закрытой панелью администратора.

## Запуск в Windows

1. Установите Node.js 20 или новее.
2. Дважды щёлкните `START-SITE.cmd` или выполните `npm start` в этой папке.
3. Откройте http://127.0.0.1:3000.
4. Для первоначальной настройки панели откройте http://127.0.0.1:3000/admin и введите одноразовый код настройки, показанный в окне сервера. Создайте пароль длиной не менее 12 символов.

Сайт открывается только на этом компьютере; окно сервера необходимо оставить открытым. Данные заявок, цены и настройки панели сохраняются в SQLite в папке `data`. У публичного сайта и панели нет заданного по умолчанию пароля.

Изображения демонстрационные и загружаются из Unsplash. Перед публикацией замените их на фотографии отеля и сверьте опубликованные цены, контакты, оценки и условия экскурсий.
